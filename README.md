# 🔐 帳號管理器 (Account Manager)

> 📑 **最新專案報告**：[📊 點此查看 2026-09-28 工作總結報告 (HTML 網頁版)](工作總結報告_20260928.html)

一個基於 **Electron** 開發的現代化、高安全本地密碼保險庫。所有帳號與密碼資料均採用軍規級 **AES-256-GCM** 演算法於本地端進行零知識加密，不需上雲、無遠端伺服器後門、資料永遠掌握在自己手中。

支援 **清爽明亮 (Light)** 與 **舒適深灰 (Soft Dark)** 雙主題一鍵切換，具備直覺的分類、標籤與自訂欄位管理，並提供一鍵產生強密碼與完整備份匯出入功能。

---

## ✨ 核心特色

### 1. 🛡️ 零知識軍規加密 (Zero-Knowledge Architecture)
- **PBKDF2 金鑰衍生**：採用 `SHA-512` 與 **100,000 次雜湊疊代**，有效抵禦暴力與彩虹表攻擊。
- **AES-256-GCM 認證加密**：確保密文防篡改，資料只在輸入主密碼後暫存於記憶體，關閉或鎖定軟體時立即銷毀金鑰。
- **純本地無雲端**：不依賴任何外部伺服器或第三方雲端，資料完全保存在您自己的電腦。

### 2. 🎨 雙主題設計與精緻美學
- **預設清爽明亮模式**：柔和白灰底色搭配清晰易讀字體，辦公閱讀舒適不刺眼。
- **舒適深灰模式**：細緻的藍灰石墨調，告別壓抑死黑。
- **一鍵無縫切換**：視窗右上角隨時按 **`☀️ / 🌙`** 即時切換，並自動記憶喜好。

### 3. ⚡ 快速啟動與便捷操作
- **一鍵啟動腳本**：目錄內提供 `啟動帳號管理器.bat`，雙擊自動完成環境檢查並秒開軟體。
- **一鍵複製**：帳號、密碼、網址皆有一鍵複製按鈕，並提供複製成功動態回饋。
- **快捷鍵支援**：
  - `F5` / `Ctrl + R`：重新整理頁面
  - `F12`：切換開發者除錯工具

### 4. 📁 彈性分類與標籤篩選
- **自訂分類**：自由新增分類、設定 Emoji 圖示與專屬顏色標籤。
- **標籤系統**：支援 `#工作`、`#常用`、`#重要` 等多標籤關聯與快速篩選。
- **即時搜尋**：支援帳號名稱、使用者名稱、網址及備註的多條件即時模糊搜尋。

### 5. 🧩 自訂擴充欄位
- 除了標準的帳號與密碼，更支援動態新增自訂欄位（如：安全問題、PIN 碼、二階段備用碼、API Key 等）。

### 6. 🎲 智慧強密碼產生器
- 內建彈性密碼產生工具，支援長度調整（8~64 位元），自由勾選大小寫字母、數字與特殊符號，一鍵產生並自動填入。

### 7. 💾 離線資料備份與還原
- **一鍵匯出**：匯出 JSON 備份檔，便於定期冷備份或更換電腦時轉移。
- **智慧匯入**：匯入時自動比對並合併分類與帳號，無失真還原。

## 🚀 快速上手

### 系統需求
- 作業系統：Windows 10 / 11 (或支援 Node.js 的作業系統)
- 執行環境：[Node.js](https://nodejs.org/) (建議 v18.0 或更高版本)

### 方式 A：直接雙擊啟動（最推薦）
直接雙擊專案目錄下的：
👉 **`啟動帳號管理器.bat`**
*(首次點擊會自動檢查並安裝所需模組，之後點擊即可秒開)*

### 方式 B：使用指令列啟動
1. 在專案目錄打開終端機（CMD 或 PowerShell），安裝相依套件：
   ```bash
   npm install
   ```
2. 啟動應用程式：
   ```bash
   npm start
   ```
3. 若需在啟動時開啟開發者工具進行調試：
   ```bash
   npm run dev
   ```

## 🔒 常見問題與安全說明 (FAQ)

### Q1：我的帳號資料儲存在哪裡？
資料經 AES-256-GCM 加密後存於 Windows 本地使用者目錄：
- **加密保險庫路徑**：`%APPDATA%\account-manager\data\vault.enc`
- **主密碼驗證檔**：`%APPDATA%\account-manager\data\master.key`

### Q2：如果忘記主密碼怎麼辦？
本軟體採用嚴格的「**零知識加密**」原則，電腦中**完全沒有儲存您的主密碼明文**，因此在密碼學上無法直接找回。
- **預防措施**：建議在軟體處於解鎖狀態時，定期點擊左下角的 **「📤 匯出」** 儲存備份檔。
- **重置保險庫**：若徹底忘記密碼且無法登入，可透過 `Win + R` 輸入 `%APPDATA%\account-manager\data`，將該資料夾清空後重新開啟軟體，即可重新註冊一組全新主密碼。
